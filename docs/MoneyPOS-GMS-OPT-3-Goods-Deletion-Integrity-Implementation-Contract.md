# GMS-OPT-3：商品删除完整性实施契约

## 范围

修正 `GmsGoodsService.delete` 的两项已确认问题：商品若仍被未删除套餐作为子件引用则拒绝删除；成功删除后回收其原品牌与分类的 `goods_count`。

## 兼容边界

- 同一批次同时删除套餐主件及其子件允许继续执行，主件的配方会按既有逻辑清理；
- 不修改路由、请求/响应、商品价格清理或“删除套餐主件配方”的既有行为；
- 不新增库存、库存单据、订单明细、会员权益或历史交易关联的删除限制；不自动级联删除这些历史数据；
- 全部校验、删除、配方/价格清理和计数回收维持在既有 GMS 商品事务内。

## 验收

- 删除被其他保留套餐引用的子件失败，商品与计数不变；
- 先删除套餐主件后可删除原子件；每次成功删除均回收对应品牌/分类计数；
- 不产生跨 Feature 依赖、迁移或历史数据改写。
