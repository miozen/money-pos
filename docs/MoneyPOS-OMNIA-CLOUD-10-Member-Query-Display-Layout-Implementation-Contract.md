# MoneyPOS OMNIA-CLOUD-10 会员查询展示布局实施契约

> 状态：已接受，实施中；确认日期：2026-10-26；适用分支：`dev`。

## 目标与边界

只整理 Omnia Cloud 网页与 Telegram 的已查询会员详情排版，使同一快照更容易扫读。不得改变快照字段、D1、POS、同步、查询条件、Webhook、权限或任何资产/权益计算。

## 冻结决定

- 会员详情固定为：姓名与手机号、品牌等级、会员资产、会员权益、最后同步时间五个视觉区块。姓名以 `👤` 标题显示，手机号以 `📱` 显示。
- 资产区块为会员余额、会员券、剩余满减券；货币统一 `¥`、两位小数和千分位。满减券继续显示张数。
- 原内部展示名“次数权益”改为业务名“寄存商品”；每项显示“商品名：剩余 数量”，不附加“次”等单位。
- 金额权益和目标权益的金额使用统一货币格式。目标权益每项分三行显示名称、进度、剩余金额；各权益项使用 `•` 分行，不再使用分号压缩。
- Telegram 使用 Emoji 与空行分组；网页使用相同区块、文案和数值格式，不引入新的前端依赖或 API。
- 空权益类别仍显示“无”，以保持详情结构稳定。

## 验收

1. Telegram 与网页均不再显示“次数权益”或“剩余 N 次”。
2. 两端的金额、满减券、品牌等级和权益数据与现有投影一致，只改变展示。
3. Worker Node 测试、既有打包/架构门禁与差异检查通过；部署后由已授权 Telegram 私聊与网页各验证一次。
