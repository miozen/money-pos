# MoneyPOS OMNIA-CLOUD-4 首次会员全量回填实施契约

> 状态：已确认，按本切片实施；确认日期：2026-10-21；适用分支：`dev`。

## 目标

在启用真实同步前，以 UMS 自有、可恢复的检查点把现有**未删除**会员放入既有 Outbox。仅 Outbox 写入发生在本地 MariaDB 事务中；远程 HTTPS 发送仍完全由 OMNIA-CLOUD-3 调度器负责。

## 约束

- `omnia.cloud.sync.initial-backfill-enabled` 默认 `false`；不开启不会扫描或标记历史会员。
- 每轮最多 1,000 人（默认 500），按租户和会员 ID 递增推进持久检查点。完成后重启不会重复全量回填；网络失败不影响检查点，因为 Outbox 保留待发记录。
- 仅未删除会员参与新云端的首次建档。删除/合并历史仍由既有 TOMBSTONE 写路径负责；不清理、不改写任何本地会员或交易数据。
- 不新增公开路由，不在业务事务内调用网络，不启用真实同步或写入任何 Cloudflare 配置。

## 验收

集成测试须证明：当前活跃会员进入 UPSERT Outbox、检查点完成后不再重复扫描。完成本切片后再进行隔离 Maven 回归、打包、架构门禁和差异检查；生产开启、密钥轮换和真实数据外发留待下一经授权运行时步骤。
