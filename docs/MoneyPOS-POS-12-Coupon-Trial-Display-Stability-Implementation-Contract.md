# MoneyPOS POS-12 会员券试算展示稳定性实施契约

> 状态：已接受，实施中；确认日期：2026-10-26；适用分支：`dev`。

## 目标与边界

只消除混合收银切换“免收会员券”时，会员券提示和最终应收下方文字短暂消失后重现的视觉闪烁。不得改变后端试算、支付金额、会员券扣减、免券语义、提交禁用、接口或数据库。

## 冻结决定

- `isTrialing` 为真时，展示层不得使用上一轮 `actualCouponDeduct = 0` 将当前购物车的理论会员券暂时置零。
- 试算中继续由当前购物车价格矩阵计算理论会员券，仅用于展示；确认收款仍受既有 `isTrialing` 禁用。
- 新试算返回并结束后，仍完全以当前后端试算结果决定实际展示和业务结果。
- 不缓存历史金额，不改变“会员券不足”条件、提示文字、POS-11 同行布局或任何服务端公式。

## 验收

1. 在应扣会员券订单中，开启或关闭免收时，顶部会员券说明和下方开关行不再经历“消失→出现”。
2. 试算中确认收款仍禁用；试算结束后显示值与后端结果一致。
3. 前端构建、后端打包、架构门禁与差异检查通过，并在 POS 人工验证开关往返切换。
