# MoneyPOS POS-13 购物车紧凑列布局实施契约

> 状态：已接受，实施中；确认日期：2026-10-26；适用分支：`dev`。

## 目标与边界

让 14 寸常见的收银屏幕在不隐藏购物车字段的前提下，同时可见序号、条码、商品名称、三类价格、数量、小计、库存和操作。不得改变商品、价格、库存、扫码、试算、结算、补货或删除业务规则。

## 冻结决定

- 序号恢复为不换行的 70px；条码 130、单价/会员价/会员券各 100、数量 140、小计 130、库存 80、操作 110 保持紧凑固定。商品名称仅设最小宽度 220px，不设上限，在宽屏自动吸收剩余空间。
- 商品名称只截断超出列宽的尾部，保留开头；悬停显示完整名称。“套餐”“满减”标签独立保留且不可截断。库存不足提示保持名称下方。
- 小计、库存、操作构成连续右固定关键列组，确保更窄窗口横向查看时收银金额、库存和操作都不被覆盖。
- 不隐藏任何列，不缩小基础字体，不改变 POS 主窗口尺寸或增加新的滚动容器。

## 验收

1. 在 1366px 宽度下，所有购物车列同时可见；小计、库存、操作不被右侧操作列覆盖。
2. 超长名称仅尾部以省略号显示，标签与库存不足提示仍可见，悬停可看到完整名称。
3. 数量输入、补货、删除、扫码、库存校验、试算与结算行为保持不变。
4. 前端构建、后端打包、架构门禁与差异检查通过，并在 POS 人工验收。
