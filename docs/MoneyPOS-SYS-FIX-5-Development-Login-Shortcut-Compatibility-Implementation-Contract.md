# SYS-FIX-5：开发登录快捷账号兼容性实施契约

## 已确认问题

登录页仅在非生产模式显示三项硬编码快捷账号（`vana`、`admin`、`guest`）。SYS-FIX-4 修改超级管理员登录名后，
该开发辅助入口仍会填入历史用户名；正式浏览器入口和桌面安装包均不渲染该区域。

## 冻结范围

1. 开发模式快捷账号改为复用已加载的 `GET /auth/login-candidates` 实时候选数据；不再保存任何硬编码用户名或密码。
2. 点击快捷项只选择当前用户名并聚焦密码输入；认证仍完全使用既有登录表单和 `POST /auth/login`。
3. 候选接口、匿名/本机限制、生产/Electron 登录界面、密码规则、权限和 token 行为不变。

## 验收条件

1. 改名后的账号在开发模式快捷区显示当前 username，旧 username 不再出现。
2. 快捷区不会预填密码；生产构建不显示该开发辅助区。
3. 普通候选选择、登录和 POS 入口不受影响。
