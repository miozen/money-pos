# MoneyPOS SYS-OPT-4：全局策略单例完整性实施契约

> 状态：**已确认，待实施**；确认日期：2026-10-16；适用分支：`dev`。

## 盘点事实

- 对现有 `money_pos.sys_strategy` 的只读盘点确认：仅 1 行，ID 为 1；唯一索引仅为主键。
- 初始化迁移也只创建一条默认策略，但数据库尚未阻止后续插入第二条策略。

## 冻结方案

1. `V1.0.22` 为 `sys_strategy` 增加固定值 `singleton_key=1` 与唯一索引，保证表中最多一条策略。
2. 迁移不更改既有策略值、ID、租户字段或读取/保存路由。若目标库已含多行，唯一索引创建必须失败并中止迁移；不得自动删除、合并或选取“权威”记录。
3. `getGlobalStrategy()` 增加稳定 ID 排序作为兼容性防御；应用服务继续更新已存在行。

## 验收

- 从空隔离库执行 Flyway 后只存在一条可读取的默认策略。
- 尝试插入第二条策略被数据库唯一约束拒绝。
- 既有策略更新保留原 ID；不新增 API、权限、跨 Feature 依赖或历史数据修复。
